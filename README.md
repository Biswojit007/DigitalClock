⏰ Digital Clock

A sleek and responsive Digital Clock built using HTML, CSS, and JavaScript.
This project displays the current time in hours, minutes, and seconds, updating every second in real-time.

🚀 Features

Real-time digital clock display

Automatically updates every second

Supports 12-hour or 24-hour format

Responsive and minimal UI design

Beginner-friendly and easy to customize

🧠 Technologies Used

HTML5 – Structure of the clock

CSS3 – Styling and layout

JavaScript (ES6) – Time logic and live updates

💡 How It Works

JavaScript’s Date() object fetches the current time.

The time updates dynamically every second.

The clock displays in a stylish, readable format.

🕒 Example Output
10:45:32 PM
